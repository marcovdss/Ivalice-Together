# In-game settings page

`scripts/` deploys to the game's `x64/scripts/` folder. With FF12's Lua Loader
and its Mod Menu plugin, it adds an **Ivalice Together** page to Mod Config:

- co-op on/off (the runtime's `ivalice-together.disabled` marker)
- Player 2/3 characters and "start with all characters" (next game start)
- each player's XInput pad and the keyboard-and-mouse owner
- menu colors by character or by player
- per-player battle menu sounds and the damage meter, including Reset

The page edits the same `x64/coop/*.json` files as `IvaliceTogetherConfig.exe`
and follows edits made there while the game runs. Button remapping and SDL pad
pairing stay in the configurator. If the full page does not fit the Mod Menu's
shared text space, a compact page without per-character colors is registered.

`IvaliceTogetherMenu/defaults.lua` is generated by
`ferramentas/gerar_padroes_menu_lua.py`; do not edit it by hand.

Tests: `testes/test_ingame_menu_lua.py` (rules against the Python loaders and
`ControlEditor`) and `testes/test_ingame_menu_page.py` (the page against a fake
Mod Menu). Both need `lupa` with Lua 5.5, the Lua version of the game's loader.

The page edits controller files only at `CONTROLLER_CONFIG_VERSION` in
`IvaliceTogetherMenu/model.lua` (11, the format of the current Together
release). Other versions leave the controller rows inactive.
